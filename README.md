# Advent of Code

Personal solutions.

| Year | Language | Layout |
|------|----------|--------|
| 2017 | Java | `2017/src` |
| 2022 | Rust | cargo workspace, one crate per day (`2022/decN`) |
| 2023 | Rust | cargo workspace, one crate per day (`2023/day-N`) |

## Puzzle inputs

Inputs are intentionally **not** in this repository. To run a day, place your own
puzzle input next to its `Cargo.toml` as the file name the solution expects
(for example `2022/dec1/input`, `2023/day-1/input_part_1`, `2023/day-10/puzzle_input`).
Those file names are git-ignored.
